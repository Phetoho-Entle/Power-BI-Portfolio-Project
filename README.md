# Data Professionals Survey Dashboard

## Project Overview
This Power BI dashboard analyzes survey data collected from data professionals across different countries and roles.

The project explores trends related to:
- Salaries in the data industry
- Job satisfaction
- Work-life balance
- Preferred programming languages
- Age distribution
- Country-based insights

---

## Tools Used
- Power BI
- Excel

---

## Dashboard Features
- Interactive filters and slicers
- Salary analysis by role and country
- Programming language comparisons
- Satisfaction ratings visualization
- Demographic analysis

---

## Skills Demonstrated
- Data cleaning
- Data visualization
- Dashboard creation
- KPI reporting
- Analytical thinking

---

## Key Insights
- Identified the most popular programming languages among data professionals
- Compared salary trends across different job titles
- Explored relationships between salary and satisfaction levels
- Analyzed responses across different countries and age groups
